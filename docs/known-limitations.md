# Known Limitations

- 対応対象は YMM4 プロジェクト JSON 内の `FilePath` です。
- 未知の YMM4 内部形式は完全には保証しません。
- YMM4 DLL はリポジトリに同梱しません。
- 複数の `YmmpxLib.dll` を同時配置する運用は非推奨です。
- アーカイブは最大 10,000 エントリ、単一素材 50 GiB、合計展開サイズ 100 GiB に制限されます。プロジェクトは 512 MiB、リンク定義は 64 MiB、プロジェクトマーカーは 16 KiB が上限です。
- 展開サイズが 100 MiB を超えるエントリおよびアーカイブ全体には、最大 1,000 倍の圧縮率制限が適用されます。
